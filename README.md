# ClipBridge

同じ Wi-Fi につながった Mac 同士で、クリップボードを直接やりとりするメニューバーアプリ。

## ショートカット

| キー | 動作 |
|------|------|
| **⌥⌘C** | クリップボードを相手に送信 |
| **⌥⌘S** | メッセージを送信（相手の画面中央に表示） |
| **⌥⌘P** | 通信の一時停止 / 再開 |

受信したクリップボードは**自動で反映**されます。あとは **⌘V** で貼り付けるだけ。

テキスト・画像・ファイルに対応。サーバーもアカウントも不要で、通信は LAN 内で完結します。

---

## インストール

```bash
git clone https://github.com/Pealsh/ClipBridge.git
cd ClipBridge
make install      # ビルドして /Applications に入れる
```

その他のコマンド:

```bash
make app      # dist/ClipBridge.app を作る
make run      # ビルドして起動
make zip      # dist/ClipBridge.zip（配布用）
make clean
```

## 使い方

1. **2 台の Mac** で ClipBridge を起動（メニューバーにクリップボードアイコンが出ます）
2. **初回ペアリング**: 両方の画面に同じ 6 桁の番号が出たら「承認」
3. 送りたい側で **⌘C** でコピー → **⌥⌘C** で送信
4. 受け取る側では自動でクリップボードに入るので **⌘V** で貼り付け

画面上部に通知が出るので、送受信できたか確認できます。

### 一時停止

**⌥⌘S** を押すと通信を一時停止できます。もう一度押すと再開。
一時停止中は送信も受信もブロックされます。

## しくみ

| 役割 | 使っている技術 |
|------|----------------|
| 端末の自動検出 | Bonjour / mDNS（`NWBrowser` + `NWListener`） |
| 通信 | TCP（Network.framework）、長さ前置フレーミング |
| 暗号化 | Curve25519 ECDH → HKDF-SHA256 → ChaCha20-Poly1305 |
| 認証 | 6 桁の照合コード（SAS）で初回ペアリング、以後は公開鍵を記憶 |
| クリップボード | `NSPasteboard`（テキスト / PNG / ファイル URL） |
| ホットキー | Carbon `RegisterEventHotKey`（アクセシビリティ権限は不要） |

同じ LAN 上にいる第三者は、Bonjour の広告こそ見えますが、**やりとりの中身は復号できません**。
ペアリング済みでない端末からの接続は、ユーザーが承認するまでクリップボードに触れません。

## 設定

### ホットキーを変える

`~/Library/Application Support/ClipBridge/hotkeys.json` を作って、アプリを再起動します。

```json
{
  "sendKeyCode": 8,
  "sendModifiers": 2304,
  "pauseKeyCode": 1,
  "pauseModifiers": 2304
}
```

- キーコードは Carbon の仮想キーコード（`C` = 8, `S` = 1, `V` = 9 …）
- 修飾キーは足し算で指定: `⌥ = 2048`, `⌘ = 256`, `⇧ = 512`, `⌃ = 4096`
  - 例: `⌥⌘` なら `2048 + 256 = 2304`

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| 相手が見つからない | 同じ Wi-Fi か確認。カフェ・大学・ホテルの Wi-Fi は「クライアント分離」で通信できないことがあります |
| 「ローカルネットワーク」の許可を拒否した | システム設定 →「プライバシーとセキュリティ」→「ローカルネットワーク」で ClipBridge をオン |
| ⌥⌘C を押しても反応しない | 他のアプリが同じキーを使っています。起動時に警告が出ます |
| ペアリングの番号が違う | **承認しないでください**。ネットワーク上に割り込みの可能性があります |
| 「壊れているため開けません」 | 右クリック →「開く」。または `xattr -dr com.apple.quarantine /Applications/ClipBridge.app` |

---

## 制限

- 同じ Wi-Fi（同一サブネット）でのみ動作。インターネット越しには使えません
- 1 回に送れるのは 100 MB まで
- フォルダの送信には未対応（中のファイルを直接選んでください）

---

## セキュリティ

- 端末の秘密鍵は Keychain に保存
- ペアリング済みの公開鍵は `~/Library/Application Support/ClipBridge/trusted.json`
- ファイル名はサニタイズされ、`~/Downloads/ClipBridge` の外には書き込みません

このアプリは監査を受けていない個人プロジェクトです。
